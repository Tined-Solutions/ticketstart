## Descubrimientos
- **Supabase pooler (puerto 6543) roto**: `openssl s_client` tira `wrong version number` — el PgBouncer no negocia SSL en este proyecto. Las queries tardaban 32s (CommandTimeout 30s + 3 retries de EnableRetryOnFailure) y daban `Failed executing DbCommand`. **Solución**: puerto directo 5432 + `SslMode=Require;Trust Server Certificate=true`.
- **WSL2 no forwardea localhost del host Windows a WSL**: el backend corriendo via `dotnet.exe` de Windows bindea a `0.0.0.0:5193`, pero `curl http://localhost:5193` desde WSL da `Connection refused`. **Solución**: acceder via la gateway default de WSL (`ip route show default | awk '/default/ {print $3}'` → 172.26.64.1), que apunta al host Windows. Esa IP cambia entre reinicios de WSL, así que se autodetecta en runtime.
- **`dotnet run --no-launch-profile` arruina el startup**: desactiva `ASPNETCORE_ENVIRONMENT=Development` y fallan los required config (JWT SecretKey, Resend, CloudflareR2). Lanzar con `dotnet run` sin flags (lee el profile `http` del launchSettings).
- **`pkill -f "dotnet.exe"` en WSL no mata procesos de Windows**: hay que usar `powershell.exe Get-Process dotnet | Stop-Process -Force`.
- **`nohup <cmd> > log 2>&1 & disown`** hace que el proceso sobreviva al timeout del bash tool de OpenCode. Sin `disown`, el proceso muere con la shell.
- **`.gitignore` raíz ya tenía `*.log`** — los archivos `.log` se ignoran solos, pero agregué `.logs/` explícito para cubrir la carpeta entera por si después meten otros formatos.
- **`frontend/.gitignore` NO ignoraba `.env`** — estaba como untracked. Agregué `.env`, `.env.local`, `.env.*.local` para evitar commitear `VITE_API_TARGET` local de cada dev.
- **gentle-ai review scope-changed**: si tocás un archivo DESPUÉS de `review start`, el `validate --gate pre-commit` falla con `scope-changed` porque el candidate tree ya no matchea el reviewed scope. Hay que empezar nueva lineage o no tocar el scope post-start.
