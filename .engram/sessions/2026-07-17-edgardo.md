## Cambios commiteados (`452f7e0`)

### 🐛 Login roto para usuarios sin nombre
**Archivo**: `backend/Services/AuthService.cs`

El admin y cualquier usuario con `Name = null` en la DB no podían loguearse. Al generar el JWT, `new Claim(ClaimTypes.Name, null)` tiraba `ArgumentNullException`. Ahora usa `?? string.Empty`.

→ **No tenés que hacer nada.**

### 🔁 Reload infinito del frontend
**Archivo**: `frontend/src/api/client.js`

El interceptor de axios redirigía a `/login` ante cualquier 401, incluyendo el `GET /auth/me` que el `AuthProvider` usa para verificar sesión. Sin cookie → 401 → redirect → reload → loop. Ahora excluye `/auth/me` y `/auth/logout`.

→ **No tenés que hacer nada.**

### 📐 Franja 4:3 en desktop
**Archivos**: `tokens.css` + 11 páginas + Footer

El CSS `#root` tenía `width: 1126px; margin: 0 auto; border-inline: 1px solid` — la app era literalmente un panel centrado con bordes. En celular se veía bien, en desktop una franja angosta.

Ahora:
- `#root` es `width: 100%`, sin bordes ni centrado global.
- Unifiqué los anchos de contenido en 3 tiers: `max-w-7xl` (dashboards/listados), `max-w-5xl` (detalle), `max-w-3xl` (formularios).
- Login, checkout y status cards mantienen sus anchos angostos (está bien así).

→ **No tenés que hacer nada.** Si ves algo raro en StaffScan, TicketLookup u OrganizerEventNew (texto mal alineado), avisame.

### ⚙️ Proxy configurable (solo para WSL2)
**Archivos**: `vite.config.js`, `.env.template`

En WSL2, `localhost` no se comparte con Windows. Agregué `VITE_API_TARGET` como variable de entorno opcional para que el proxy de Vite apunte a la IP correcta. El default sigue siendo `localhost:5193`.

→ **No tenés que hacer nada.** Tu `.env` actual sigue funcionando igual.
